System Architecture & Features

About ErrinILS

ErrinILS is an open-source, zero-dependency Integrated Library System (ILS) built specifically to solve the real-world operational challenges of school libraries.

Engineering Philosophy

Zero Dependencies. Maximum Reliability.

Most enterprise library systems require heavy stacks: Apache, PHP, Python, MySQL/MariaDB, Node.js runtimes, or cloud subscriptions. When a school PC has no internet or is managed by a teacher without IT background, those stacks fail.

Pure Base .NET 4.0

Written entirely in pure C# using only the base assemblies shipped with Windows (mscorlib, System, System.Drawing, System.Windows.Forms). No NuGet packages, no third-party DLLs, and no registry pollution.

Runs on Legacy Hardware

School computers are often 8 to 15 years old with limited RAM. ErrinILS runs comfortably on 1 GB RAM and consumes less than 15 MB of memory under active circulation load.

Single JSON Database

All bibliographic records, patrons, loans, and settings reside in a single human-readable file (errin-data.json). Backing up or migrating your entire school library takes two seconds: copy one file or use built-in ZIP export.

Complete Feature Matrix

Engineered for School Librarians

5-Source ISBN Copy-Cataloguing

AUTOMATED

Adding new books takes seconds instead of minutes. Scan an ISBN-10 or ISBN-13 barcode, and ErrinILS queries 5 international bibliographic sources in priority sequence:

  • 1. Library of Congress: Native ASN.1 BER over Z39.50 v3 (lx2.loc.gov:210).
  • 2. Open Library: Modern REST API with full bibliographic JSON parsing.
  • 3. Google Books API: Global ISBN database with publisher descriptions and dates.
  • 4. HathiTrust: Academic union catalogue via MARCXML retrieval.
  • 5. K10plus German Union: SRU MARCXML service for international acquisitions.

MARC21 Standard Interoperability

ISO 2709

ErrinILS is built on international cataloguing standards. You can import or export records without vendor lock-in:

  • ISO 2709 Binary MARC: Raw binary .mrc record parser and generator.
  • MARCXML: W3C standard XML format with schema validation.
  • MRK (Mnemonic Text): Human-readable MARC records compatible with MarcEdit.
  • MARC-8 & UTF-8: Built-in converter for MARC-8 combining diacritics and character tables.

QR Code Remote Access & Multi-Wi-Fi

NEW v1.3.1

Teachers, student librarians, and stock audit assistants can access the library system wirelessly from smartphones and tablets without installing any app:

  • Zero-Dependency QR Engine: Pure C# ISO/IEC 18004 QR generator (EC-Level M) rendering sharp SVG and PNG codes.
  • Password-Free 6-Digit PIN: Secure pairing model with 5-minute expiry and 3-attempt lockout.
  • Cryptographic Device Token: Generates a persistent 32-byte X-Errin-Token stored in browser localStorage.
  • Multi-Network Binding: Pure C# HTTP server (`TcpListener`) binds to 0.0.0.0, working across 2.4/5GHz SSIDs, hotspots, and Tailscale meshes.

Simplified Student Self-Checkout Kiosk

KIOSK MODE

Primary and secondary students can independently manage their book borrowings without librarian supervision:

  • Child-Friendly UI: Oversized high-contrast touch targets, cheerful colors, and friendly wording (Lib.Friendly).
  • Audio-Visual Feedback: Distinct pleasant chime on success; warning buzz on overdue or hold restrictions.
  • Restricted Librarian Exit: Protected by admin password (default: admin123) to prevent students from exiting into administrative settings.

Circulation Rules & School Localization

CIRCULATION

Tailored specifically for school operations and regional student identification:

  • Malaysian IC / MyKid: Validates format (YYMMDD-PB-###G), birth month (01–12), and valid calendar day.
  • Fines & Limits: Configurable daily fine rate (default RM 0.10/day) and borrowing block threshold (default RM 5.00).
  • Hold Queue: Prevents other patrons from borrowing titles reserved by fellow students.
  • GDPR / Data Retention: Built-in 5-year activity purge for graduated student privacy.

Executive Reports & Collection Analytics

ANALYTICS

Gives school principals and library coordinators deep visibility into reading participation:

  • Reading Champions: Top student reader leaderboard tracking total books read (ideal for Nilam / reading awards).
  • Circulation Trajectory: Monthly checkout volume trends over the last 6 months.
  • Collection Classification: Dewey Decimal 100s distribution breakdown and dormant zero-circulation audits.
  • 1-Click CSV Export: Instant spreadsheet generation for school board presentations.
Native Per-Monitor V2 High-DPI Sharpness

Many older Windows desktop applications become blurry when running on modern 1080p, 2K, or 4K laptops set to 125%, 150%, or 200% display scaling. ErrinILS embeds native Windows PerMonitorV2 awareness directly in its executable manifest. All UI elements, fonts, tables, and buttons render with crisp ClearType vectors without GPU overhead.
