System Architecture & Features

About ErrinILS

ErrinILS is an open-source, zero-dependency Integrated Library System (ILS) built specifically to solve the real-world operational challenges of school libraries.

Engineering Philosophy

Zero Dependencies. Maximum Reliability.

Most enterprise library systems require heavy stacks: Apache, PHP, Python, MySQL/MariaDB, Node.js runtimes, or cloud subscriptions. When a school PC has no internet or is managed by a teacher without IT background, those stacks fail.

Pure Base .NET 4.0

Written entirely in pure C# using only the base assemblies shipped with Windows (mscorlib, System, System.Drawing, System.Windows.Forms). No NuGet packages, no third-party DLLs, and no registry pollution.

Runs on Legacy Hardware

School computers are often 8 to 15 years old with limited RAM. ErrinILS runs comfortably on 1 GB RAM and consumes less than 15 MB of memory under active circulation load.

Single SQLite Database

All bibliographic records, patrons, loans, and settings reside in a single ACID SQLite database file (errin-data.db). Backing up or migrating your entire school library takes two seconds: copy one file or use built-in 1-click export.

Complete Feature Matrix

Engineered for School Librarians

31-Source ISBN Copy-Cataloguing

31 SOURCES

Adding new books takes seconds instead of minutes. Scan an ISBN barcode, and ErrinILS queries 31 free Malaysian and international library sources in priority sequence:

  • Malaysian Union & National: Pustaka Terbuka Union, KIK (National Union), Perpustakaan Negara Malaysia (PNM Clarivate Discover), and u-Pustaka.
  • State Public Libraries (14 States): Selangor (PPAS), Penang (PPAP), Perak, Kedah, Perlis, Johor, Kelantan, Terengganu, Pahang, Negeri Sembilan, Melaka, Sarawak, Sabah, Kuala Lumpur, Putrajaya, and Labuan.
  • Academic & Heritage: MALCat Union, Universiti Malaya (UM), UKM Tun Seri Lanang, UiTM PTAR, UPSI, and Dewan Bahasa dan Pustaka (DBP).
  • International Archives: Library of Congress (Z39.50), Open Library, Google Books, HathiTrust, and K10plus German Union.

MARC21 Standard Interoperability

ISO 2709

ErrinILS is built on international cataloguing standards. You can import or export records without vendor lock-in:

  • ISO 2709 Binary MARC: Raw binary .mrc record parser and generator.
  • MARCXML: W3C standard XML format with schema validation.
  • MRK (Mnemonic Text): Human-readable MARC records compatible with MarcEdit.
  • MARC-8 & UTF-8: Built-in converter for MARC-8 combining diacritics and character tables.

Android Scanner App & Wireless Wedge

NEW v1.4.3

Turn any Android phone or tablet into an enterprise barcode gun using the dedicated ErrinILS Scanner APK:

  • Wireless Barcode Wedge: Streams scanned barcodes over Wi-Fi directly into the active cursor of your PC circulation desk via /api/wedge.
  • Continuous CameraX ML Kit: Sub-second barcode recognition under difficult library lighting conditions.
  • Mobile Copy-Cataloging: Scan ISBNs directly in the remote access web interface with instant union catalog search and direct catalog commits.
  • Multi-Network Binding: Pure C# HTTP server (`TcpListener`) binds to 0.0.0.0, working across 2.4/5GHz SSIDs, hotspots, and Tailscale mesh.

Simplified View

SIMPLIFIED VIEW

Primary and secondary students can independently manage their book borrowings without librarian supervision:

  • Child-Friendly UI: Oversized high-contrast touch targets, clear status banners, and friendly wording (Lib.Friendly).
  • Visual Status Feedback: High-contrast status banner color changes (green for success, red for errors, yellow for warnings).
  • Simple Exit: Dedicated button to return immediately to the librarian dashboard when the session ends.

Batch Label & Spine Printing

NEW v1.4.3

Print physical shelf and copy labels in bulk with zero third-party software:

  • Multi-Select Support: Select multiple items with Ctrl+A, Shift-click, or row selection on the catalog table.
  • Barcode Labels (3.5" × 1.1"): Code 128 barcode, library name header, call number, and book title.
  • Dewey Spine Labels (1" × 1.5"): High-contrast call numbers split across multiple lines for shelf spine visibility.
  • Live Preview: Interactive antialiased preview with Prev/Next cycling and copies-per-record selector (1–50).

Dual Cloud Sync (Drive & GitHub)

MULTI-PC SYNC

Zero-dependency multi-PC synchronization separating private patron records from public catalog data:

  • Google Drive for Students: Private student records, active loans, and fines sync directly over HTTPS without installing desktop apps.
  • GitHub for Catalog: Bibliographic records sync to GitHub following the Pustaka Terbuka Data Provider standard (PPAPP model).
  • Zero-Dependency Git: Works via local Git CLI or pushes commits directly over HTTPS using the GitHub REST API.
  • Multi-PC Parity: Connect multiple classroom workstations to the same school cloud repositories seamlessly.

Circulation Rules & School Localization

CIRCULATION

Tailored specifically for school operations and regional student identification:

  • Malaysian IC / MyKid: Validates format (YYMMDD-PB-###G), birth month (01–12), and valid calendar day.
  • Fines & Limits: Configurable daily fine rate (default RM 0.10/day) and borrowing block threshold (default RM 5.00).
  • Hold Queue: Prevents other patrons from borrowing titles reserved by fellow students.
  • GDPR / Data Retention: Built-in 5-year activity purge for graduated student privacy.

Executive Reports & Collection Analytics

ANALYTICS

Gives school principals and library coordinators deep visibility into reading participation:

  • Reading Champions: Top student reader leaderboard tracking total books read (ideal for Nilam / reading awards).
  • Circulation Trajectory: Monthly checkout volume trends over the last 6 months.
  • Collection Classification: Dewey Decimal 100s distribution breakdown and dormant zero-circulation audits.
  • 1-Click CSV Export: Instant spreadsheet generation for school board presentations.

Online Public Access Catalog (OPAC)

WEB OPAC

Students, teachers, and parents can search the library collection from any device on the school network:

  • Local Network Web OPAC: Served at /opac matching the signature desktop dark theme (charcoal, golden yellow accents, royal blue branding).
  • Dedicated Subject Heading Search: Search by Perkara / Subject Heading alongside Title, Author, and Call Number, with live topic cloud tag filtering.
  • Patron Self-Service Login (Optional): Disabled by default; when toggled ON in Settings, students log in with their Student ID or Malaysian IC (no_pengenalan) to view active loans, due dates, fines, history, and place holds on borrowed books.
  • Real-Time Copy Availability: Immediate visual indicators of shelf availability, on loan due dates, and hold status.

Static Hosting & GitHub Pages Export

STATIC OPAC

Schools without a dedicated server or constant computer uptime can host their OPAC 24/7 for free:

  • 1-Click Export: Go to Settings → "Export Static OPAC (GitHub Pages)" to generate a complete deployment package (index.html, catalog.json, opac-standalone.html, and README.md).
  • 100% In-Browser Search: Fast multi-token fuzzy search, subject heading filtering, and sorting run entirely client-side with zero external dependencies.
  • Zero Server Costs: Deploy to GitHub Pages, Cloudflare Pages, Netlify, or static school hosting with zero maintenance and zero IT administration.
  • Standalone Single-File Mode: Includes opac-standalone.html with embedded catalog data that can be double-clicked directly off a USB drive or local network share without even a web server.
Native Per-Monitor V2 High-DPI Sharpness

Many older Windows desktop applications become blurry when running on modern 1080p, 2K, or 4K laptops set to 125%, 150%, or 200% display scaling. ErrinILS embeds native Windows PerMonitorV2 awareness directly in its executable manifest. All UI elements, fonts, tables, and buttons render with crisp ClearType vectors without GPU overhead.
