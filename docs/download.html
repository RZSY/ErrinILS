A Note on Windows 7 and .NET Framework

Windows 8, 8.1, 10, and 11 come with .NET Framework 4.5+ already installed by default; ErrinILS will run immediately out of the box. If you are deploying on older Windows 7 SP1 computers, ensure that Microsoft .NET Framework 4.0 (or .NET 4.8) is installed. If needed, you can download the official .NET 4.8 runtime directly from Microsoft's website.

Installation Walkthrough

Step-by-Step Setup Instructions

METHOD A

Installing via Windows Setup Wizard (Recommended)

Follow these 4 simple steps to install ErrinILS on a library circulation computer:

  1. Download: Click the Setup Installer (.exe) button above.
  2. Run Installer: Double-click ErrinILS-Setup-1.3.2.exe in your Downloads folder.
  3. Follow Wizard: Choose your install location (defaults to C:\Program Files (x86)\ErrinILS) and click Install.
  4. Launch: Check the box "Launch ErrinILS" or launch it anytime from your Start Menu or Desktop icon.
METHOD B

Running Portably from a USB Flash Drive

Ideal if you share computers or want a zero-install deployment:

  1. Download the Portable ZIP Package.
  2. Extract the contents to your USB drive (e.g. E:\ErrinILS\).
  3. Double-click ErrinILS.exe to begin working immediately.
  4. Tip: To backup your database to the USB stick, use the built-in Export Backup (ZIP) feature in the Settings tab.
Windows SmartScreen Note ("Windows protected your PC")

Because ErrinILS is an open-source binary released without an expensive commercial code-signing certificate, Windows Defender SmartScreen may display a blue warning screen: "Windows protected your PC".

This is normal for newly released open-source software. Simply click "More info" and then click "Run anyway". You can verify the integrity of the binary using the SHA-256 hash provided above.

METHOD C

Upgrading from an Earlier Version (e.g. v1.2, v1.3.0, or v1.3.1)

Upgrading to v1.3.2 is 100% safe and seamless:

  1. Close any running instances of ErrinILS.
  2. Run the new ErrinILS-Setup-1.3.2.exe installer (or replace ErrinILS.exe).
  3. Your catalog, patrons, loan records, and fine balances are preserved intact in %APPDATA%\Errin\errin-data.db (with automatic migration from legacy errin-data.json).
Initial Administrator Password: admin123

ErrinILS is protected by a default administrator password: admin123. You will be prompted for this password when opening the Settings tab, deleting catalog items or students, and restoring backups. You can set your own custom password anytime in Settings → Admin Password.

Developers & Administrators

Build from Source in 5 Seconds

ErrinILS requires no Visual Studio. You can compile the full production executable using Windows' built-in C# compiler:

PowerShell (Windows Built-in csc.exe) 
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
    /target:winexe /optimize+ /debug- `
    /win32icon:icon.ico `
    /r:System.Drawing.dll,System.Windows.Forms.dll `
    /out:ErrinILS.exe *.cs
